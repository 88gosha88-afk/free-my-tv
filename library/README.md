# Free My Library

Медиатека для телевизора и проектора на Android: фильмы и сериалы с диска, подключённого к роутеру, с постерами,
описаниями, сезонами и сериями, прогрессом просмотра. Диск читается по сети (SMB), файлы не копируются.

## Что умеет

- Главный экран: «Продолжить просмотр», «Недавно добавлено», кнопки «Фильмы», «Сериалы», «Папки», «Настройки».
- Названия и годы берутся из имён файлов и папок (русские и английские, релизные вроде `Movie.2012.1080p.BDRip.mkv`),
  описания, постеры, рейтинг и названия серий — с TMDB на русском.
- «Папки»: дерево диска; на любой папке (стрелка вправо или удержание OK) — добавить в медиатеку как фильмы, сериалы
  или «авто», исключить, вернуть. Исключить можно и отдельный файл.
- Субтитры и озвучки в отдельных файлах (`.srt`, `.mka`, папки `Subs`, `Rus Sound`) подхватываются сами.
- Название можно поправить вручную («Название…» в карточке), если описание нашлось не то.
- Воспроизведение — встроенным проигрывателем на libVLC: читает все форматы, DTS и AC3, внешние и вшитые субтитры,
  сам выбирает русскую озвучку, запоминает место, включает следующую серию. Файл он читает с диска сам (smb://), а если
  не получилось — через адрес приложения. В «Настройках» можно переключиться на внешний VLC. libVLC скачивается при
  первой сборке (около 100 МБ); `abis=` в config.properties оставляет только нужные процессоры и уменьшает приложение.

## Сборка

Нужны те же инструменты, что и для основного приложения (JDK 17, Android SDK, `adb`), плюс `curl` и `zip`.

```
cd library
./build.sh        # первый раз создаст config.properties и скачает три библиотеки (jcifs-ng, slf4j, bcprov)
```

Откройте `library/config.properties` и проверьте адрес диска, список папок и (по желанию) ключ TMDB; потом снова
`./build.sh`. Ключ TMDB, если он уже есть в `config.properties` основного приложения, берётся оттуда. Установка:

```
adb connect <адрес приставки>:5555
adb -s <адрес приставки>:5555 install -r FreeMyLibrary.apk
```

Файл `library/library.keystore` сохраните: обновления подписываются тем же ключом.
